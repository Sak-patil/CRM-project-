# Basic Instructions

These instructions apply to every AI agent working on this project.

## Before Work
1. Read `CONTEXT.md`, `PHASES.md`, and `PROJECT_STATUS.md`.
2. Read the relevant technical/phase documentation.
3. Inspect the existing code before modifying it.
4. Do not assume missing requirements; ask when a decision is needed.

## Development Cycle
Follow:

PLAN
↓
IMPLEMENT
↓
TEST
↓
REVIEW
↓
DOCUMENT
↓
UPDATE PROGRESS

### Plan
- Understand the task, scope, dependencies, and risks.
- Present the plan before significant implementation.

### Implement
- Work only within the current phase/scope.
- Follow the existing architecture and conventions.
- Avoid unnecessary dependencies or unrelated changes.

### Test
- Verify normal cases, edge cases, errors, and relevant security/permissions.
- Never claim something works without verification.

### Review
- Check correctness, security, maintainability, performance, and complexity.

### Document
- Update relevant documentation to match the actual implementation.

### Update Progress
- Update `PROJECT_STATUS.md`.
- Update `PHASES.md` when a phase status changes.

## Rules
- Do not silently change requirements or major architecture decisions.
- Do not implement future phases unless explicitly instructed.
- Do not mark work complete if completion criteria are not satisfied.
- Stop after completing the current phase and wait for the next instruction.
